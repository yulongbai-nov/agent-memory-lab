# CouchDB/PouchDB 合成同步实验

在本目录运行 `./run.sh`（需 Node.js、Docker Compose 和镜像下载网络），脚本创建独立项目、网络和数据卷，结束时停止该项目的容器并保留卷及 `results/<运行标识>/`。测试凭据是公开合成值，只用于内部网络；不映射主机端口。请勿将其用于生产。

测试持续运行的嵌入式 PouchDB 断网写入和重启持久化、三方最终收敛与重复同步、语义冲突及追加解决。镜像摘要及 npm 依赖锁定。CPU/内存是 Docker 稀疏快照，不含虚拟机整体开销，样本不是性能基准；未验证手机、浏览器、真实多设备及数据库修订冲突。

Mac 本地实验曾使用 Colima（2 核、3 GiB、12 GiB 数据盘；另有 20 GiB 根盘）；GitHub Actions 使用 Linux 主机 Docker 环境，资源和虚拟化不同，不能直接比较数值。全新 CouchDB 初始日志可能短暂提示缺少 `_users`；系统库创建并重启后脚本会检查相应警告。PouchDB 精确依赖的 UUID 8.3.2 有已知审计问题，实验通过 npm override 使用 11.1.1；本地测过 CommonJS、v4 随机 ID、非确定性修订及本实验同步，但跨主版本覆盖并未全面兼容性认证。
