# Local find preview

`memory find --preview` is an explicit local CLI view. Without `--preview`, CLI output is unchanged; MCP, bounded relay and Web do not receive these fields. It keeps the existing candidate ordering, topic keys, counts and paging. The default remains at most five candidates.

Each selected group adds `groupLabels` (`来源会话`, `命名话题`, or both), `matchedItems` and at most three `previewCitations` deduplicated by full source identity and logical item. Existing `count` still counts matching archive versions and qualifying review associations. Each representative is chosen from the versions that passed the existing filter; a newer nonmatching version never replaces an older match. When the same item's matching projection is identical, a version recorded as having an original can be preferred. This is a recorded property only: `archived-recorded` does not establish that the original is currently readable or verified. Missing original metadata is `source-only`; no original file is opened.

`preview` is null or one literal excerpt from a matching archived ordinary user/assistant message, with an exact same-version `citation`, `label: 归档消息`, `selection`, `text`, `truncated`, and `originalAvailability`. A keyword excerpt comes only from message text that itself matches under the existing case-fold rule. A pure time-range excerpt is labeled `时间范围内片段`. A group matched only through review text, metadata, tool output or a system event has no excerpt. The bound is 240 UTF-8 bytes without splitting Unicode code points. If the keyword cannot fit, the text is malformed, or the projection contains an obvious credential, personal path or email pattern, the excerpt is omitted rather than altered. This conservative check is not a complete sensitive-data classifier.

The CLI emits JSON; opt-in preview also escapes C1 and directional terminal controls on the wire while preserving parsed values. The excerpt is a redacted archive projection, not a semantic summary, a confirmed decision, a claim about who authored it, or evidence that an original is available. A user can choose a topic for the existing timeline or resolve the exact citation through the existing evidence interface. The opt-in path performs an additional scoped projection read and currently materializes all matching projection bodies before selecting the displayed page; this is not a bounded large-archive scan. Page-limited retrieval is a separate performance follow-up. It makes no model call and does not inspect original bytes.
