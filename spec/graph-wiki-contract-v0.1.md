# Graph + Wiki 查询契约 v0.1（提案）

第一轮从项目工作页或知识主题页找到同一条已审决定，打开局部关系图或时间线，核对 DSH 原决定、澄清和 Codex 后续变更，再接续已审待办。[用户已确认的设计边界](graph-wiki-design.md) · [合成案例](../benchmark/graph-wiki/README.md)

## 入口、身份与范围

项目工作页和知识主题页是平级入口。两者沿用服务端绑定的 `scope = {owner, project}`。浏览器传入的 `scope`、候选标题、页面链接和图节点 ID 都不能扩大访问范围。初版的 `topic` 是该范围内现有查询的精确选择值。它可以承接 `find → timeline/current`，改名、别名、同名主题和跨项目主题需要单独的稳定主题身份设计。

同一对象从任何入口打开都应保留相同身份。决定使用 `(scope, review_id)`。同一条决定的历次评审有不同 ID，靠 `revises` 连到原评审。待办使用现有 `root`，即 `(scope, {kind: "annotation", id})` 或旧版精确来源根。来源身份是 `(scope, source.harness, source.instance, source.session, id, revision)`，其中 `revision` 是归档版本 ID。`turnId` 是命中该版本之后读取的展示坐标，可缺失。查询、图、Wiki 和待办之间以这些身份连接。独立评审即使同名也保留各自身份。旧版无 `review_id` 的审阅条目可保留精确来源身份，相关对象关联需要显式验证。

| 操作 | 现有字段与初版要求 |
| --- | --- |
| 候选 | `find` 接受话题或时间线索，默认约五个候选，显示实际数量和更多结果提示。返回 `topics[]`（`topic`、`count`、`latest`、`citations`）及 `coverage`。初版用现有主题选择值。支持来源会话组和命名主题组时应标明其含义。若展示预览，沿用[同版预览规则](find-preview-v0.1.md)。 |
| 当前决定 | `current` 的 `review_id`、`label`、`citation`、`effectiveCitation`、`pending` 足够支持首轮已审决定导航。前者引用原评审依据，后者只在当前文字由独立纠正证据支持时出现。歧义显示候选及原因。 |
| 局部图与时间线 | 目标是先取所选主题的有界窗口，必要时再翻页或展开；当前实现先读取完整主题，再将图响应限制为 100 条并提示截断。时间线保留 `review_id`、`kind`、`label`、`revises`、`citation`、`annotations`，待办行另带 `task_state`。图保留同一批对象的身份和原有状态，初版只连有显式记录的关系，悬空目标应提示范围或来源缺口。页面链接仅用于导航。图与时间线应提供可通过键盘打开来源的文字列表。 |
| 精确证据 | 使用 `evidence({id, revision, source})`。服务端绑定 `scope` 并验证完整身份。显示 Harness、实例、会话、条目、版本、原时间及已知 `turnId`。候选、图和时间线使用同一证据面板。 |
| 接续 | `task-list` 沿用分页与 `next_step`，待办详情沿用 `task_state` 和来源引用。首轮也可从所选主题的待办行展示接续动作。 |

现有 Web 的 `find`、`current`、`timeline`、`evidence` 可复用。当前 Web `timeline` 返回完整数组，分页需接到现有操作层或增加有界读取。现有操作层时间线默认 20、最多 50，候选每组最多三条引用。首轮图响应限制为 100 条并标明截断，尚无底层分页。服务端扫描范围、硬字节上限和稳定分页需要独立验证。组件沿用 Cytoscape.js 与 vis-timeline，由接口提供身份、关系和时间语义。

## 证据可用性

打开引用只解析指定版本。即使同一条目有更新版本，也保留原引用及文本。可以显示已知旧版并另列新版本。只有能证明版本关系时才标记当前或旧版。原会话、归档版本和已接受评审保留追加历史。

| 查询结果 | 展示含义 |
| --- | --- |
| `original.availability: archived` | 当前归档原件文件通过本地存在、权限和大小检查。只有明确读取并核对哈希，才能标记原件已核验。 |
| `source-only` | 精确归档版本可用，原件未捕获。按实际内容标识为归档文本或片段。 |
| `missing-locally` | 已有原件记录，本地文件不可用。仍显示可用的精确归档版本。 |
| 精确版本缺失或不匹配 | 标记该引用不可用。保留范围内可见的引用和缺口。拒绝用同名条目、邻近时间、其它实例、其它范围或最新版替代。跨范围请求用与缺失相同的外部错误边界。 |

来源版本的缺失、哈希失败、片段限制和源会话覆盖缺口分别呈现。当前 `evidence` 返回可用性，但普通 Web 证据面板没有哈希验证结果。现有图投影遇到缺失或不完整证据可整体拒绝，局部界面保留缺口的行为有待实现。

## 决定、纠正与任务

- **已确定**来自可解析的 `basis: confirmed`、`lifecycle: active` 评审。生效的显式确认变更沿 `revises` 替代同一决策链内前项。前项在时间线上标记**已替代**，保留精确依据。将来的确认变更先显示预定生效时间，边界到达后才切换当前决定。
- 图里的 `revises` 首先表示显式指向哪个评审。只有两端均已确认、有效且变更在查询时点已经适用，查询或投影才可标明 `SUPERSEDES` 并导出前项的已替代状态。初版只有 `revises` 时显示“变更指向”或“提议指向”，并保留查询返回的状态。
- **待决定**来自显式提议 `basis: proposed`。**待核实**可来自 `basis: uncertain` 或影响当前答案的歧义，包括无法确定适用时间、证据不一致和竞争中的确认分支。提议与待核实分支可以显示，不能替代有依据的当前决定。无法确定唯一适用确认项时返回候选和原因。
- **已取消**须有明确评审 `lifecycle: cancelled`。仅在其范围、目标和适用时间能确认时，撤下对应当前决定。保留历史依据。当前查询有取消状态，图投影尚未统一表示取消因果。五态在界面均用文字及颜色表达，首轮验收以已确定、待决定及可见历史链为主。
- `correction` 通过 `revises` 定位被误记的评审，`target` 继续指向原证据，`evidence` 如有则指向独立澄清消息。它改变当前所知的表述而保持决定的因果身份。人工声明没有新证据时照实显示。`change` 来自用户后续实际改变，通过自身 `target` 与 `revises` 分别提供新证据和因果关系。两者都保留原记录。纠正使用已验证的追加操作。[数据契约](contract-v0.1.md)
- 执行状态由现有 `task-state` 观察及其 `parents` 决定。`open` 有下一步，`unmarked` 可保留旧提示并标注状态未记录。`paused` 或冲突压住下一步，`completed`／`cancelled` 从待办列表移除并留在历史。源观察有独立消息引用，操作员声明明确标注。会话结束、决定变更和任务完成之间不推导状态。[任务契约](task-state-observations.md)

## 时间语义与实现边界

| 时间 | 可用字段与显示 |
| --- | --- |
| 表达时间 | 精确归档消息的 `timestamp`／`time`。未知或无法解析时按[查询时间语义](query-time.md)保留未知。初版时间线行 `time` 可能来自评审的 `valid_time`，明确按该行时间含义显示。 |
| 适用时间 | 显式 `valid_time`／关系侧车 `effectiveAt`。现有决定与投影允许以源时间为保守支持下界。用作证据下界时不得声称它是用户明确指定的生效时间。精确生效边界含该瞬间。未知且影响答案时报告待核实。 |
| 系统知晓时间 | 现有来源 `observedAt`、v2 审核 `reviewedAt`、任务 `recordedAt`、显式依赖侧车 `knownAt` 各自只证明本事件的观察或记录。普通决定和纠正缺可通用验证的知晓时间。晚到材料可以表达更早的事实，图重建和索引写入时间不能替代首次知晓时间。 |

`asOf` 用于问某时点适用什么。需要回答“截至某时系统知道什么”时，另用独立的 `knowledgeCutoff`。已知晚到的材料可影响回看，在其记录之前的知晓视图中排除。未知的必要知晓边界应显示未知。原始决定 ID 的生效切换可验证，而旧纠正在某历史时点的准确表述或当时是否已知可能仍不可答。现有 `current(asOf)` 与 `answerDependency` 各只覆盖部分语义。后者的 `knowledgeCutoff` 约束显式依赖关系，不能把其结果当成所有评审和任务的历史知晓状态。完整历史双视图的产品范围仍待决定。

首轮可组合现有作用域、审阅 ID、引用、当前决定查询、时间线和任务状态。持久主题 ID、通用评审知晓事件、取消图边、统一缺口及存储层有界读取、稳定分页是后续提案。当前图响应最多返回 100 条并提示截断，底层仍先读取所选主题的完整时间线；缺少完整来源的审核项会标明数量并省略。当前不写入归档。首轮语义边来自显式评审和可验证的关联，依赖关系继续使用[投影的独立批准侧车](ontology-projection-v0.1.md)。Graphiti 仍待对照，物理存储方案仍待决定。新的读接口或适配器使用严格 TypeScript，保留运行时验证、范围检查、lint 和 CI 门禁。
