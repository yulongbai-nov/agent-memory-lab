# 中期验收记录

| 能力 | 公开合成证据或代码状态 | 验收边界 |
|---|---|---|
| 归档和恢复 | 合成回归覆盖追加版本、条件推进 checkpoint、坏行轮转、截断缺口、DSH 序号补回及收集器续接。 | 仍缺失的序号保留缺口。私有全量覆盖单独核验。 |
| 原件和本机历史 | DSH 多帧输入、Codex 活跃与归档目录、归一化 ChatGPT 快照均有合成覆盖。原件按字节哈希保存；敏感值变化产生独立版本。 | 快照契约适用于本机归一化文件。原始导出转换、未捕获原件及私有历史覆盖分别验收。 |
| 决定和未完任务 | 公开协议回放通过两端真实 CLI 的 MCP 请求，检查有界查找、当前决定、时间线、待办和两处精确引用。CLI、MCP 与网页的范围隔离有合成回归。 | 公开回放的模型由本地模拟提供方替代。原生深链、Remote 和手机访问单独验收。 |
| 用户复核 | 合成决定、纠正、实际改变、待定变更、取消和待办有追溯记录。浏览器提交及同一重试 ID 的幂等有合成覆盖。 | 用户经既有复核入口追加账本。草稿保持待核实。 |
| 待审草稿 | 本机 CLI 显式范围内列出最新快照并打开单项，核对归档引用、旧版和原件状态。发行包用合成资料验收。 | 详情局限于已选快照和本机作用域。模型质量和私有数据验收分别记录。 |
| 同步和权限 | 临时 CouchDB 的合成双档验证覆盖角色权限、离线批注汇合、覆写拒绝和范围隔离。 | 跨主机 TLS、常在线主机和真实手机另行验收。 |
| 浏览器离线 | 合成配置覆盖断网、重载、重开后的已保存目录和草稿，恢复后以同一重试 ID 提交。 | 原文访问需要在线。真机安装和整机重启另行验收。 |
| 每日整理 | 合成连续运行、迟到纠正和草稿续接覆盖可重建索引及队列。每次显式启用的草稿阶段最多处理一个本地批次。 | 定时注册、自然触发、私有推理和非空候选各有独立验收。 |

合成语义构建保留了早期运行事件未通过校验的记录。后续公开夹具的成功批次通过候选与引文校验，同一输入复跑命中缓存。修订后的缓存验证运行来源，真实 CLI 与注入测试使用各自的命名空间。私有运行的历史阻断、空批次和验收计量保留在本机。

公开回答端首轮找到下一步但缺少独立证据调用。后续合成任务验证了 find、timeline 和 evidence。隔离 Linux 另行运行公开协议回放和带预算的模型任务，两者按各自提交及运行证据记录。[隔离运行说明](../benchmark/harness-e2e/README.md)

文件检索保留为基线。当前合成实验比较文件、结构化和图谱候选及固定预算内组包；另有显式时间和依赖请求的证据组包与独立留出。实验分别记录候选支持、组包支持、引用及模型输出，结论限于各自夹具。[合成评测说明](../benchmark/memory-views/README.md)

本机索引使用 SQLite 事务写入。迁移保留归档原件、条目版本、用户账本、批次、checkpoint 和覆盖元数据，保留旧 JSON。详见 [本机索引 ADR](adr-local-sqlite-index.md)。
