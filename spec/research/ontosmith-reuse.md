# OntoSmith 复用评估

评估于 2026-11-11，仅审阅 OntoSmith 官方仓库与 Agent Memory Lab 的公开设计。本文没有执行 OntoSmith 安装或运行验收。官方源码以提交 `9bc8981de162473987e7b1515d9506b37423d2f7` 固定；文档中的能力与项目自身的质量数据不等同于本项目验收。

## 结论

OntoSmith 值得参考其**类型定义、证据检查和人工批准流程**，暂不建议用它替代现有归档、同步或决定时间线。它更接近从文档构建受约束的知识图谱；本项目的主要要求是保留原件、准确回到来源版本，并解释决定如何随时间变化。Graphiti 的时序记忆能力与 HY 的写入流程另行评估。

现有小型本体投影已按公开规格实现确定性重建：只处理已复核批注和准确来源版本，不调用模型或修改 Tier 0；`asOf`、纠正、冲突与独立依赖证据均有明确边界。其验收仍以合成资料为主，不代表生产图谱或多端部署已验收。[本项目投影规格](../ontology-projection-v0.1.md)

## 对照

| 需求 | OntoSmith 已核实情况 | 对本项目的含义 |
|---|---|---|
| 类型与审核 | 定义实体、关系、边界例子和属性；模式经过校验与人工批准，批准绑定哈希，发布为版本化包。外部 OWL/RDF 通过清单和人工范围说明导入，类型层级被简化为平面类型，逻辑公理不按原有 OWL 语义保留。 | **可借鉴**类型边界、显式审批和哈希绑定；它不是 OWL 推理引擎，也不替代现有审核事件。 |
| 不可变原件 | SQLite 注册表保存实体与决定记录；Neo4j 是图投影。源码规定一个当前图，身份不同的构建会替换旧投影，注册表保留历史。 | **必须适配**：Tier 0 原件与来源版本仍由本项目的私有归档管理；图可删除、重建，不能作为唯一原件库。 |
| 来源与证据 | 记录提供文档 ID、证据引文、批次等；检索可返回句子或片段。源码的佐证 ID 包含事实、文档、表面形式和引文；写入者缺少表面或引文时可能退化为事实加文档。 | **必须适配**到会话、轮次、消息和准确修订；句子检索或引文不自动证明原始字节偏移，也不能保证同文档重复佐证都独立保留。 |
| 决定时间演进 | 项目支持批次及模式版本；未查到满足本项目要求的决定有效时间、获知时间、纠正与历史 `asOf` 查询的完整契约。 | **未验证**：保留现有投影的时间和歧义规则；Graphiti 是否更适合时序记忆仍需独立测试，不能由此推断它已满足要求。 |
| 多端同步 | 构建依赖 Neo4j；文件模式可回读已完成的记录，演示可离线查询。未发现与 CouchDB 离线双端同步等价的保证。 | **未验证**：CouchDB 同步和 SQLite 本机索引继续按现有设计；离线读取不等于离线构建、跨端收敛或手机验收。 |
| 模型、成本与数据流 | 实时构建需要 Neo4j 和模型席位。默认提议、判断和嵌入经配置的供应商；Jev 判断模型在默认 OpenRouter 路由下使用同一账户和密钥，无需单独 Jev 注册。可换判断席位，但原有阈值和质量记录不再自动适用；美元上限需明确设置。 | **必须适配**：证据与文本可能发送到所绑定服务；先核实各席位的数据流、账户权限、价格及上限。`p_true` 是排序分数，不是经过校准的真实概率。不得把默认设置当成本地、免费或零外发。 |

当前架构中的 CouchDB 双端结果是合成实验，真实跨主机和手机仍另行验收；HY 的写入权、冲突及权限机制也须单独验证。OntoSmith 的样例 API 文档说明其无认证和 TLS，应保持本机隔离，不能直接作为远程服务。

## 仅合成资料的最小验证提案

以下提案用于后续独立评估。

1. 使用互相独立的虚构对话：周二决定、对原说法的纠正、周三生效的变更、相互矛盾的来源，以及同一文档两处相同引文。给每条来源准备稳定的会话、轮次和修订标识。
2. 首先只在隔离环境检查其免密钥的资料画像、模式校验、已记录样例检索和证据输出；核对模式批准是否绑定哈希、引文能否映射回准确来源修订，并记录不支持的字段。
3. 若之后单独决定做真实图构建，再使用可丢弃的独立 Neo4j 和仅含合成资料的模型连接，先核实各席位外发路径并设置费用上限。检查重复构建、图替换及清理；用时间边界、迟到纠正和冲突案例比较本项目投影结果。不得连接现有归档或生产同步库。

**退出条件：** 若无法可靠定位准确来源修订、不能区分纠正与实际变更、无法保留冲突或历史时点、无法隔离外发与费用，或实验可能触及现有图与原件，则停止，不把结果接入现有写入或同步链路。即使通过，也只说明这些合成案例通过，不能证明真实数据质量或生产就绪。
